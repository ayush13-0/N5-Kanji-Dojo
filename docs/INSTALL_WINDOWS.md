# Windows Installation

1. Download `N5-Kanji-Dojo-Setup-v1.6.exe` from the official GitHub Release.
2. Check its SHA-256 hash against the value published with that release.
3. Run the installer.
4. Review the publisher shown by Windows before proceeding.
5. Complete the setup wizard and launch N5 Kanji Dojo from the Start Menu or Desktop shortcut.

## Windows SmartScreen

An independently distributed application may display a SmartScreen warning. Do not advise users to bypass it blindly. Verify the source, signature, publisher and checksum first. A self-issued certificate is not automatically trusted by Windows and is not equivalent to a certificate issued by a trusted public certificate authority.

## Audio

Open Settings → Audio on this device. The application handover says v1.6 prefers installed Japanese female voices such as Microsoft Haruka, Ayumi or Nanami. If no Japanese voice is installed, add one through Windows speech settings, then restart the application if required.

## Updating and uninstalling

Use the official installer for updates. The handover says uninstalling does not delete study progress, but verify this behaviour before relying on it. Back up important exported vocabulary where possible.
