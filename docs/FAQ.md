# Frequently Asked Questions

## Does the app work offline?

The project handover describes the Android v1.6 build as offline and the desktop builds as offline-first. Verify each exact release before making a universal guarantee.

## Why is there no Japanese audio?

The app uses system speech facilities. Install a Japanese text-to-speech voice in the operating system, test it outside the app and restart the app.

## Which Windows voice should I use?

The v1.6 handover says the app prefers Japanese female voices such as Microsoft Haruka, Ayumi or Nanami. Availability depends on installed Windows speech components.

## Which macOS package do I need?

Use Apple Silicon for M-series Macs and Intel for Intel Macs.

## Will an update keep my progress?

The handover says progress is stored locally and earlier Android updates retain it when signed with the same key. Back up important data before updating and verify the update path.

## Where are the installers?

They should be attached to the corresponding GitHub Release. This source repository package does not contain the installers.

## Is the app open source?

The included LICENSE currently reserves all rights. Do not describe the project as open source unless the owner chooses and applies an appropriate open-source licence.
