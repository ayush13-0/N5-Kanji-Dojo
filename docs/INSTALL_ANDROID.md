# Android Installation

1. Download `N5-Kanji-Dojo-v1.6.apk` from the project's official GitHub Release.
2. Open the downloaded file using the Android Files app.
3. If Android asks, allow installation from that source.
4. Review the installer prompt and install.
5. Open N5 Kanji Dojo from the app drawer.

## Updating

The handover says v1.6 uses the same signing key as earlier Android versions. If Android rejects an update due to a signature mismatch, do not uninstall immediately if local progress matters. Confirm the package source and signing certificate first.

## Compatibility

The earlier project handover says Android 8 or newer. Confirm the actual v1.6 manifest and test devices before treating that as a guaranteed requirement.

## Audio

The app uses the phone's configured Japanese text-to-speech voice. Install a Japanese voice in the device's text-to-speech settings if speech is unavailable.
