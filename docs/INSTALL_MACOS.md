# macOS Installation

Choose the package matching the Mac processor:

- Apple menu → About This Mac → Apple Silicon (M-series): Apple Silicon package.
- Intel processor: Intel package.

1. Download the corresponding ZIP from the official GitHub Release.
2. Extract it.
3. Move N5 Kanji Dojo to Applications.
4. Verify the download checksum and code signature where provided.
5. Launch the application.

macOS may warn about software from an unidentified developer if the app is not Developer ID signed and notarized. Do not bypass security warnings unless you have verified the package source and integrity. The project handover described right-click → Open as the first-launch path for the earlier build; current macOS security behaviour may differ.

## Audio

The v1.5 handover says speech uses the macOS `say` command and the installed Japanese system voice. Check available voices in macOS settings if Japanese pronunciation is unavailable.
