# Contributing

Thank you for your interest in N5 Kanji Dojo.

## Before contributing

- Search existing issues before opening a new one.
- For security issues, follow [SECURITY.md](SECURITY.md), not a public issue.
- Keep changes focused and explain the user-facing impact.
- Do not include private data, signing credentials or copyrighted learning material without permission.

## Pull requests

Include:

1. A concise problem statement.
2. The proposed change.
3. Platforms affected.
4. Testing performed, including device / OS and version.
5. Screenshots or a short recording for UI changes, where useful.
6. Documentation updates where behaviour changes.

## Japanese learning content

For kanji, vocabulary, readings, meanings and example sentences, cite a reliable source and check accuracy. Preserve attribution and licensing requirements for diagrams, fonts, datasets and other third-party resources.

## Code quality

Follow the conventions already used in the relevant platform source. Do not introduce new dependencies without explaining why they are needed and documenting their licence and security implications.

## Release changes

Only maintainers should create signed release artifacts. Contributors must not upload private signing material.
