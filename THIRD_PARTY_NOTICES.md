# Third-Party Notices and Attributions

This project handover mentions **KanjiVG** as a source requiring licence attribution and says that attribution was included in the application and a bundled licences file in an earlier package.

The actual licence text and exact version of each third-party asset must be included in `licenses/` before release.

| Component / resource | What to record before release |
|---|---|
| KanjiVG | Exact source/version, copyright notice, applicable licence text, modifications and attribution |
| Fonts | Font family, source, version and licence |
| Icons | Icon set, version, licence and required notices |
| Libraries / frameworks | Name, exact version, licence and notices |
| Japanese datasets / dictionaries | Dataset name, source, version, licence and attribution |

Do not assume that mentioning a resource here satisfies its licence. Add the actual licence files and an accurate software bill of materials (SBOM) for each platform release.

See `licenses/README.md`.
