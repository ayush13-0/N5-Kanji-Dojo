# Changelog

All notable changes recorded in the supplied project handover are listed here. This is a reconstructed history; consult source control and release artifacts for exact commit-level details.

## [1.6] - 2026-11

### Android
- v1.6 package reported ready and installed successfully.
- Reported offline operation and zero Android permissions.
- Existing Android signing key retained according to the handover.

### Windows
- Japanese female voice preference refined.
- App reportedly prioritises available Japanese female voices such as Microsoft Haruka, Ayumi and Nanami.
- Audio device settings identify the voice / fallback mode.

### macOS
- Latest recorded macOS packages remain v1.5 for Apple Silicon and Intel.
- Native macOS speech integration reported through `say`.
